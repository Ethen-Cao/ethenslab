# EV high-spec architecture diagrams

`index.html` is a self-contained page with the electrical/electronic, IVI hardware, and high-level software architecture views. Open it directly in a browser.

Edit the Python, HTML, CSS, JavaScript, or TSV sources in this directory, then regenerate the page:

```sh
python3 build.py
```

The build also refreshes `architecture.svg` and `ivi-hardware.svg`. Commit the edited sources and regenerated outputs together. `template.html` is a build template; open `index.html` for the finished page.
