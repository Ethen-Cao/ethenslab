# Hardware visual contract

本文件规定硬件视图的构图与语义；数值以 `assets/tokens.json` 为机器来源。规则中“必须”用于语义与一致性，“优先”用于允许调整的布局。以下尺寸均为 draw.io 逻辑 px，在 100% 缩放下验收。

## Compact device cards

| 项目 | 普通器件 | 接插件 |
| --- | --- | --- |
| 固定高度 | 80 | 48 |
| 图标槽 | 48 × 48 | 24 × 24 |
| 图标实际最大外接尺寸 | 40 × 40，等比 | 24 × 24，等比 |
| 左右内边距 | 12 | 8 |
| 图标槽与文本间距 | 12 | 8 |
| 文本起始 x | 72 | 40 |
| 主名 | 16，行高 20，最多两行 | 13，行高 18，默认一行 |
| 说明 | 12，行高 16，最多一行 | 不另设底部说明区 |
| 主名与说明间距 | 4 | 不适用 |

- 节点宽度按内容以 8 的倍数扩展，不强求全图同宽。普通节点不按内容增高、不局部缩字。型号、数量与位宽不要靠省略号或截断适配。
- 普通文本组高度 = 主名实际行数 × 20 + 有说明时的 4 + 16；组 y = (80 − 组高) / 2。主名和说明左边缘一致，各自文本框只容纳真实行高。无说明则主名独立居中，不保留空行。
- 图标槽垂直居中，实际图形按外接框等比缩放并作小幅光学居中；不能把摄像头、显示屏等强行拉成正方形。所有图标使用同一描边语言，图标内标识不能比说明更抢眼。
- 接插件只允许 13 → 12 的有界字号调整；优先加宽，仍不可读时把非身份说明移到图外，而不是继续缩小。默认检查器按单行验收；用户明确要求换行时，应同步声明并调整例外的布局与检查，不能悄悄增高接插件或忽略检查错误。
- 标签示例：`Coax (Connector)`、`J11 (FAKRA ×4)`、`USB Type-C`。具体位置号优先于泛称；未知形态用 `Connector`，不虚构型号或连接器系列。
- 接插件宽度 = `ceil((2 × paddingX + iconSlot + iconGap + 实际标签宽度) / 8) × 8`，不能统一使用 208 / 240 或示例列宽。当前 13 px 模板参考宽度保存在 `tokens.json → connector.referenceWidths`：Connector 112、USB Type-A / Type-C 128、J11 (FAKRA ×4) 144、Coax (Connector) 160、Shielded (Connector) 176。这些数值只适用于对应标签，不是其他名称的最大宽度；新标签测量后按网格取整，并渲染复核无换行、无截断。
- 主名是器件类别或已确认实体；说明放型号或一项必要规格。型号原样保留。`Powered microphone inputs` 可以是一行说明，不为它额外增加内边距或独立背景框。

### Allowed height exceptions

- **SoC / MCU**：为实际端口数量保留足够的端口间距；内容紧凑，主名与型号成组，不用巨大空白衬托核心。
- **Container**：ECU、Board、功能分组按真实内容确定大小，它们不是普通器件。
- **Port breakout**：J1、B2B 等确需展开多端子的连接器可使用 `layoutClass=port-strip` 的端口容器，显式标明其唯一身份。紧凑 connector 与展开容器选一种表达，不重复画两份器件。不得借此给 DSP / SerDes 改高度。

## Symbols

| 实体 | 使用的符号与区别 |
| --- | --- |
| SoC / MCU / DSP / ADC / PHY / Transceiver | 芯片轮廓，类型标识与名称对应；Audio ADC 不写成泛泛 IC |
| Camera | 视频摄像头轮廓：机身、侧面镜头与小支撑；不用相机照片图标 |
| Display | 无底座的宽幅薄边框车载面板 |
| Touch Display | 同样的面板 + 接触点 / 指尖标记；视频链和触摸链分别连接 |
| HUD | 独立投影器与倾斜投影面，不直接复用 Display |
| Microphone / Speaker / Amplifier | 对应轮廓；功放是器件，不把喇叭图标放在功放位置 |
| DRAM / Flash Storage | 物理存储器符号，区别于逻辑 Buffer |
| Shared Buffer | 堆叠矩形表示内存资源，不能表示一个额外存储芯片 |
| Coax connector | 屏蔽外壳、同心圆与中心触点；只在确认时标 FAKRA |
| Shielded connector | 外壳与成对触点；只在确认时标 HSD 等系列 |
| USB Type-A / Type-C | 分别为矩形偏置舌片 / 圆角口居中舌片，前提是形态已知 |
| Generic connector | 外壳与示意触点，适用于物理制式未知的接口 |
| A2B | 总线写在线上；节点使用 `A2B Transceiver` 芯片符号；接插件按其物理形态另选 |

不使用照片、品牌 Logo、Emoji 或整块位图代替这些器件。图标内部的示意触点、引脚和屏幕内容不构成电气规格。

## Layout and boundaries

1. 处理核心不等于只有 SoC。SoC、MCU、外部 DSP 可并列、分行或局部展开；链路围绕直接连接的器件组织。
2. 局部链路优先左到右；允许 Mic 和 Speaker 同侧或上下排列，前提是实际连接更清晰。不能为了输入列 / 输出列把它们改接到 SoC。
3. 已确认的两块板放入各自 Board 容器，再放进真实 ECU 边界。跨板信号通过已知 B2B 独立端子，未知端子编号不编造。SoC 芯片内外与板卡内外是不同边界。
   归属未知的器件不能仅凭图上位置判定为 ECU 外部；可暂列在明确标注 `Placement unspecified` 的非物理分组，或省略未确认的边界并在图外说明。影响主图边界判断时先询问。
4. 容器标题左上，预留独立 header，至少 40 高；内容从 header 下方开始，边距至少 16。不得让连接线穿过标题。视觉分组不能假装为物理容器：显式注明功能分组，使用与实体边界有区别的线型。
5. 普通相邻卡片至少间隔 24；有线标签的通道按文本实际长度扩展，不能把“最小间距”当所有标签都能装下的保证。
6. 共享图像内存围绕真实读写链布局：Camera → 接收 / DMA → Buffer → 消费者；渲染输出则 GPU → Buffer → 显示读取。位置由生产与消费关系确定，不固定放所有硬件下方，不把控制线当像素流。

## Color, status and lines

节点填色、边框与图标保持中性。下面仅按**信号族**给线着色，不同时承担厂商、职责或配置状态含义。

| 信号族 | 颜色 | 示例 |
| --- | --- | --- |
| Video | `#356DC9` | MIPI CSI-2 / DSI / DP / LVDS / GMSL / FPD-Link 视频链 |
| Audio | `#8055B5` | Analog audio / I2S / TDM / A2B |
| Communication | `#087F83` | SPI / I2C / USB / Ethernet / CAN / LIN |
| Discrete Control | `#5F6368` | Reset / Enable / Interrupt / GPIO 控制 |
| Power | `#BE532E` | Supply / VBUS / 明确的供电轨 |
| RF | `#846342` | Antenna feed |

- 默认线宽 1.8；连续音视频主链需要强调时统一用 2.6，不由线宽推断带宽或性能。设备边框与线条轻重保持协调。
- 信号方向确定才画单箭头；明确双向才画双箭头；只知道物理连接时无箭头。协议名本身不能证明应用数据方向。
- 图例只保留图中实际出现的颜色和特殊标记。统一写 `Data`，不使用 `Data / pixels`。硬件图已有信号族时不额外重复一套 Data / Control 配色。
- Included 使用普通外观；Reserved / Optional / DNP 使用清楚的文字或 badge，辅以中性浅色 / 虚线。三者含义不同，不互换。仅在来源确认时保留预留链路，不能为预留器件创造连接。
- 复用 SerDes 链路的控制通道可在同一真实链路标签中注明；只有材料确认独立线缆或通道时才另画，避免把逻辑信息画成新增物理接线。

## Routing, ports and labels

- 正交连接。先调换同排节点、排序入口和规划通道，消除非必要交叉；无法消除时用原生 arc 跨线桥。
- 单路优先接边中点；多路入口按远端顺序排列。每条独立信号拥有独立端口，不为了整齐让多条边在同一点叠加。
- 路线不能穿无关节点、图标、文字或标题。相邻独立走线至少间隔 12；多个端口建议至少 16；末段至少留 16 的直线路径，并垂直进入目标边界。
- 48 高的四通道接插件可在侧边使用 y = 6 / 18 / 30 / 42 的独立端口，按 12 的最小间距布线；这不是四路合一的 junction。端口更多而无法满足间距时使用明确的端子展开容器，不任意拉高普通 connector。
- 标签归属于边，位于直线段附近并避开折点、箭头与交叉；标签与节点至少留 8。保留足够长的直线段，再放文字，不用白色标签底掩盖错误交叉。
- 真实共享分支使用实心 junction；非连接交叉没有 junction。四路独立摄像头不能先汇成一点再进入 SerDes。
- 不同线尽量不长距离重合；多条线终点处不要为追求同一个“顶部中心”人为交叉。优先入口排序，而不是每条线分别绕行。

## Visual acceptance

在全图和 100% 局部同时检查：普通节点高度一致；单行说明无大块留白；图标不变形；型号不截断；接插件字不小于 12；header 清楚；边界与功能分组不混淆；每条线可追踪；灰色状态仍可读。机器检查不代替这一步。
