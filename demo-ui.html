01. 跨虚拟机显示架构分层职责

在 SA8295 / SA8797 智能座舱平台中，Android Guest (GVM) 负责应用渲染与图层合成规划，而物理显示控制器 (DPU/MDSS) 由 Host 侧 (QNX 或 Linux PVM) 的 OpenWFD Server 独占管理。

02. 缓冲导出与零拷贝提交流程

Android 侧 Gralloc 分配的受保护或普通图形缓冲不会通过内存拷贝跨 VM 传输，而是通过 HAB 导出物理页表引用（Export ID），Host 侧 `wfd_be` 调用 `habmm_import` 映射至 SMMU 页表后直接交由 DPU 扫描输出：

// Guest 侧导出图形缓冲句柄并提交帧元信息
habmm_export(hab_handle, dma_buf_fd, size, &export_id, HABMM_EXPIMP_FLAGS_DMABUF);
wfd_wire_commit_pipeline(dev, pipe, export_id, acquire_fence);

03. 常见显示黑屏与 Fence 超时排查路径

当出现跨屏卡顿或黑屏时，优先核对 `qcdisplaycfg.xml` 管道分配、`hab` 通道状态及 Host 侧 `openwfd_server` 的 VSync 提交计数。
